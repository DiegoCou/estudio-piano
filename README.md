# Estudio de piano

Herramientas para practicar piano conectando un teclado digital por MIDI (USB) en Chrome o Edge.

- **Entrenador de lectura:** notas en clave de Sol, de Fa o en las dos, en vista de una nota o de partitura, con o sin escala (armadura incluida).
- **Analizador de escalas:** mide la regularidad del ritmo y del volumen nota a nota, los errores y la sincronía entre manos.

Página: https://diegocou.github.io/estudio-piano/

Los resultados se guardan solo en el navegador de cada dispositivo.
